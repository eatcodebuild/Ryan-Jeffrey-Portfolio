# Ryan Jeffrey Portfolio Website — Technical Overview

This repository hosts my full-stack portfolio website, designed and built to demonstrate my capabilities as a software developer through a clean, performant, and professional online presence.

---

## Architecture & Technology Stack

- **Frontend:**

  - Built using semantic **HTML5** and **CSS3** for structured content and styling.
  - Utilizes **Bootstrap 5.3** for responsive design and consistent UI components, ensuring the site adapts seamlessly across all devices.
  - Implements **JavaScript (ES6)** and **jQuery** for dynamic UI behaviors, smooth scrolling navigation, and interactive elements.
  - No heavy frontend frameworks used, prioritizing fast load times and simplicity.

- **Backend:**

  - Developed with **Node.js** and **Express.js** to serve static and dynamic content efficiently.
  - Uses server-side routing to deliver multiple views and handle HTTP requests gracefully.
  - Incorporates **Nodemailer** for handling contact form submissions, enabling direct, secure email communication without exposing backend logic on the client side.
  - Environment variables managed via **dotenv**, securing sensitive credentials like SMTP login details.

- **Deployment & DevOps:**
  - Hosted on a modern cloud platform (e.g., Vercel) supporting Node.js applications with seamless CI/CD integration from GitHub.
  - Application optimized for performance by minimizing external dependencies and leveraging CDN-hosted assets where appropriate.

---

## Key Features & Design Considerations

- **Professional Responsive Design:**  
  The website employs Bootstrap’s grid system and utilities to deliver a mobile-first experience, ensuring accessibility and usability on all screen sizes from smartphones to desktops.

- **Clean Separation of Concerns:**  
  Frontend assets (CSS, JS, images) are neatly organized under a public directory, while backend logic and routing remain modular and maintainable.

- **Interactive Contact Form:**  
  A fully functional contact form processes user input on the server, validates and sanitizes data, then sends inquiries securely via email — showcasing practical backend integration and security best practices.

- **Performance & Maintainability:**  
  Lightweight JavaScript usage and minimal dependencies keep the site fast-loading and easy to maintain, reflecting a pragmatic engineering approach.

- **Security Practices:**  
  Sensitive information like email credentials are never hard-coded and are securely managed through environment variables, reducing risk exposure.
